## 4. 可直接实施的计算合同

### 4.1 用同一膜节点电荷方程取代经验冲突比例

当前NRC膜电容接地，漏电阻接vrest。取流入膜为正、分流/其他外流为正，则：

`Cm·[vm(b)−vm(a)] = ∫[Iin−Ish−(vm−vrest)/Rm−Iother]dt`。

`Iother`包含实际复位、恢复、POR和其余连接端子的带符号电流；MOS门端位移电流不能凭空忽略。这里不需要、也不要求全网物理闭合，只处理正在声明的关系核支持。

实施边界：

1. 删除`HC_STRONG_THRESHOLD=0.8`及0.5/0.3经验否决；不得另换一个无推导的绝对电压或比例。
2. 每次进入报告同一时间窗的Qin、Qsh、Qleak、其余已测/有界项、实际电容变化及残差；Cdir的Qsh始终参与核算，不依赖hc是否越过某个标签门槛。
3. 结合已有来源支持判断该进入得到多少净支持。净作用不足却声称获得对应膜上升，不能PASS；实际分流极弱且来源、净支持充分的进入，不应因hc残尾被否决。
4. CHAIN已有完整膜节点terms，应复用；FULL定点探针只测注入和kh，不能写成其余项已经实测。其余项必须有当前测量或由既有元件方程得到的明确保守界；不足时为UNMEASURED，仅补必要测量，不新增科学case。

### 4.2 从已知初态连续携带电荷，不能从局部最低点重新开账

从协议/原始记录中可确认的物理初态开始，或者从有明确复位与状态来源证据的锚点开始，覆盖到被评事件。若使用后者，应保留锚点形成证据。对全部支持区间逐段记录注入；支持结束时电荷按实际动力学保留、泄漏，实际复位/恢复按真实支路扣减。**不得在cause间隙、q下降沿或局部argmin处无条件重置来源账。**

用于验证实现的被动膜精确式（vrest恒定，u=vm−vrest，τ=Rm·Cm）是：

`u(b)=exp(−(b−a)/τ)·u(a)+(1/Cm)∫exp(−(b−s)/τ)·[Iin(s)−Ish(s)]ds`。

有复位/恢复等支路时把其真实带符号电流纳入；vrest移动时可直接在接地电容的vm方程上积分：

`vm(b)=exp(−Δt/τ)·vm(a)+∫exp(−(b−s)/τ)·[vrest(s)/τ+(Iin−Ish−Iother)/Cm]ds`。

用这类连续状态账区分此前合法支持留下的贡献和支持外/无来源的贡献。不是只检查最新一段增加的几毫伏；也不是把任意非零起态当成合法历史。采用原误差合同，不把上述必要账本冒充所有模型项已经测全的证明。
